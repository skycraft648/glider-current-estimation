# 最终筛选版研究方法说明

## 上游来源与公开边界

上游 CTD/TCM 数据清洗、质控与部分既有物理模型输出来自课题组项目既有流程；公开仓库不提供相关源代码，也不声明其为个人独立实现。

本仓库的公开代码从**私有任务级汇总文件**开始，利用冻结的 Stage7/Stage8 任务级估计进行二次分析，并重新训练下游 ML。数据来源与处理边界必须保留。

## 疑似航向异常任务保守剔除

基于已有原始 TCM 航向审计表，按 TaskName 与既有 299 任务汇总表进行一对一连接。只要该任务存在负航向记录（在归档中全部位于 -327.68 至约 -295° 的疑似回绕带），就整任务排除。共有 76 个被排除任务，对应 50,993 条负航向观测记录；剩余 223 个任务。

*这种规则可能剔除编码后本可还原的有效数据，也会改变日期/海区分布；不是科学上的唯一真值校准方法。*

## 物理估计比较

保留任务中的上游 Old / GlobalMean / LinearCarry 估计不变，按相同筛选口径计算与 CMEMS 0–500 m、0–200 m 参考的二维矢量差。有效配对任务数分别为 193 和 199。这里并未重新运行上游物理估计。

## 机器学习

基于保留任务、配对合格、时间深度参考覆盖率 >=80% 的数据，使用固定日期阈值划分训练 (113)、验证 (16) 和测试 (64)；训练 Ridge、RBF-SVR、Random Forest 的残差修正预测，使用验证集选择模型。公开脚本保留归档中固定参数，不以测试集重新调参。

同时报告零海流和训练参考均值基线，避免只报告比已有模型更好、却不优于简单参考的指标。

## 统计与局限性

- 覆盖率阈值为 80%、85%、90%、95%，阈值提高后样本数显著变化（95% 仅 3 个配对任务），相关指标应谨慎使用。
- 按日期聚类的 3,000 次 Bootstrap 用于检验模型差的稳定性，不等同于物理真值标定。
- 重算复用了之前匹配的 CMEMS（数值模式）参考；不应表述为“现场实测海流真值”。
- 测试集上 Ridge 的模式参考差异为 0.06588 m/s，仍高于零海流基线 0.04652 m/s。
